# 부산보건고등학교 교사 AI 업무 심화 연수

NotebookLM에서 자료 검색과 작성 요청을 준비하고 외부 AI로 양식 문서를 완성하는 120분 연수용 정적 웹사이트입니다. 사전답사 계획서 작성·조건 변경·재사용을 기본 실습으로 하며, PowerPoint·Excel과 스킬 설치는 선택 응용입니다.

## 배포

GitHub Pages: `main` 브랜치 `/docs` 폴더. 외부 AI API나 키를 사용하지 않습니다. 사이트 입력은 브라우저에서만 처리되며 제출 서버가 없습니다. 학습 체크 상태만 localStorage에 저장됩니다.

## 개념과 실습

왼쪽 ‘RAG와 NotebookLM’ 목차에서 자료와 AI, RAG 처리 순서, 직접 구축에 필요한 자원, 도구별 역할, 작성 요청 전달, 결과 검토를 여섯 화면으로 배웁니다. NIST·Microsoft·Google 공식 출처를 각 설명에 연결했습니다. NotebookLM에서 자료 검색과 외부 AI용 작성 요청을 준비하고, 원문 발췌와 원본 양식을 외부 AI에 전달해 문서를 완성하는 흐름입니다. 서비스 사이의 복사·첨부는 사람이 하며 자체 RAG 서버를 구현한 것으로 설명하지 않습니다.

진행 계획은 총 120분입니다. 개념 10분, 자료와 양식 준비 5분, 검색·원문 확인 20분, 작성 요청 20분, 휴식 10분, 외부 AI 문서 작성 20분, 조건 변경 15분, 파일 검토 10분, 저장·공유·질문 10분으로 구성합니다. 계정은 사전에 확인하며, 전체 시간은 교실에서 측정한 소요 시간이 아닌 수업 운영 계획입니다.

2026.10.18. 실제 브라우저에서 현장체험학습 매뉴얼의 서식 7을 사용해 NotebookLM → 작성 요청 → Claude 문서 생성을 확인했습니다. 가상 날짜·시간·인원 변경이 본문과 표에 반영됐고, 원본 DOCX와 PDF의 내용 및 렌더를 대조했습니다. Claude Pro 계정에서 PDF 서식을 DOCX로 재구성한 사례이며, 무료 계정이나 HWPX 원본 양식 보존까지 확인한 결과는 아닙니다.

각 이론 탭의 심화 설명은 총 6개 장·24개 주제입니다. `docs/content/rag-theory.json`이 웹 전문과 PDF 심화 요약의 공통 원본이며, `python scripts/build-theory-notes.py`로 HTML을 갱신합니다. 교재 PDF는 같은 내용의 요약과 복사할 검색·작성 요청을 포함합니다.

## 자료

`docs/references/`: 공식 공개 자료와 검색용 변환본. 원문 URL, 적용일, 수집일, 파일 해시는 공개 자료 목록에 기록합니다. 학교 원본 공개 자료와 법령·교육청 지침을 구분하고 최신본 여부는 원문에서 재확인합니다. 학교 내부 자료·개인 학생 자료는 포함하지 않습니다.

`docs/assets/notebook/`: 로그인된 실제 서비스에서 공개 자료로 진행한 NotebookLM 실습 캡처. 사이트에 표시한 기준일의 화면이며, 실제 도구 UI와 기능은 변경될 수 있습니다.

`docs/downloads/`: 공개 자료 묶음, 시작 자료 PDF 3종 묶음, 가상 예산 CSV, 강의 교재 PDF. `automation/`에는 사전 테스트의 원본 서식·첫 작성 PDF·변경 후 PDF·NotebookLM 작성 요청 TXT가 있습니다. Word 수업계획안의 다운로드 링크는 제공하지 않습니다.

- `teacher-ai-lecture.pdf`: 16:9 가로형 53쪽. 2쪽은 제공 이력서에서 발췌한 강사 사진·재직·학력·강의 기록. 표지와 마지막 쪽에 공개 사이트 QR 코드가 있습니다.
- `teacher-ai-lesson-plan.docx`: 이전 진행안을 별도 보관한 수업계획안 2쪽. 사이트 다운로드 메뉴에서는 제외했습니다. 최신 진행 순서는 사이트와 강의 PDF를 기준으로 합니다.
- 원본 이력서와 추출한 연락처는 배포 폴더에 포함하지 않습니다. 강사 소개에 필요한 사진과 경력 요약만 교재에 포함합니다.

## 디자인

사용자가 2026.10.15 마지막으로 확정한 네 번째 이미지 화면을 기준으로 구현했습니다. 흰색 학교 로고 헤더, 연한 파란색 번호 목차, 큰 남색·청록색 제목, 문서 3장 그림, 수업 순서 4단계와 PDF 3종 카드가 홈에 배치됩니다. 같은 헤더·목차·색상으로 이론·자료실·작성 요청 준비·문서 완성 화면을 연결합니다. 첫 화면에 기본 실습 문서와 전후 비교 경로를 추가했습니다. 이론은 여섯 개 탭, 실습은 17단계이며 화면 위·아래에서 단계를 이동할 수 있습니다. 추가 AI 도구와 스킬은 접힌 보조 메뉴에서 이용합니다. 학교 로고 출처는 `docs/assets/school-logo-source.json`, 생성 그림 기록은 `docs/assets/school-document-flow.provenance.json`, 글꼴·아이콘 라이선스는 `docs/assets/third-party-assets.md`에 있습니다.

기존 공개 자료와 서비스 캡처를 보존했습니다. 사이트 자체 화면 3장은 2026.10.18. 현재 UI로 다시 촬영했으며, 입력 예시는 원본 양식의 항목 정리이고 규정 문장의 직접 인용이 아님을 표시합니다. `design-qa.md`에 선택 시안과 실제 화면 비교, 브라우저 검증, 문서 렌더 검토를 기록합니다.

## 검증

`scripts/check-site.cjs`: 링크/파일 존재, 자료 목록, JS 구문 검사.
`scripts/serve.cjs`: 로컬 개발 HTTP 서버. 기본 포트 4173.
`artifacts/`: 배포 및 화면 검증 증거(커밋하지 않음).
`output/`: 최종 문서의 로컬 사본(배포본은 `docs/downloads/`).
`scripts/build-lesson-plan.py`, `scripts/build-lecture-pdf.py`: 문서 작성 스크립트. 강사 소개 원자료는 로컬 `artifacts/selected-build/profile.json`과 추출 사진을 별도로 사용합니다.

라이선스: 직접 제작한 사이트 코드 MIT. 외부 스킬 및 공공 자료의 이용 조건은 각 원문을 따릅니다. 공식 스킬 원문을 이 저장소에 재배포하지 않습니다.
