01자료를 준비하고 등록하기

아래 공개 자료실에서 학교·교육청·법제처 자료를 받습니다. HWP·HWPX 원본은 읽기용 PDF 또는 TXT 변환본과 구분합니다.

  1. NotebookLM을 열고 새 노트북을 만듭니다.
  2. 노트북 제목에 업무와 기준일을 적습니다.
  3. 소스 추가에서 다운로드한 PDF·TXT를 등록합니다.
  4. 자료 제목·시행일·적용 대상을 확인합니다.
공개 자료실로 이동 ↗
02필요한 자료만 선택해 검색하기

처음부터 모든 규정을 한꺼번에 적용하지 않습니다. 질문의 학교급·업무·시점을 정하고 소스 패널에서 관련 자료를 선택합니다.

활동: 학교 자료만 선택한 답변과 학교·교육청 자료를 함께 선택한 답변을 비교합니다.

실제 캡처 질문: “부산보건고 학교규정집의 수행평가 결시 처리에서 추가 평가의 기본 원칙을 찾아줘.” 관련 소스 3개를 선택한 뒤 답변의 인용을 확인했습니다.

03인용을 눌러 원문 대조하기

답변의 인용 번호를 눌러 원문을 엽니다. 해당 조항이 답변을 실제로 뒷받침하는지, 예외나 적용 대상이 빠졌는지 확인합니다.

완료 기준: 근거 2개를 직접 확인하고, 자료에 없는 질문에는 ‘추가 확인 필요’를 표시합니다.

04근거 묶음을 외부 AI에 전달하기

확인한 발췌문·출처·문서 양식·검토 기준을 묶어 외부 AI에 전달합니다. NotebookLM 채팅에 요청해 작업 지시문을 만들 수 있지만 별도의 ‘프롬프트 생성 버튼’ 기능은 아닙니다.

ACTUAL SCREEN / 실제 실습 캡처

2026.10.14 실제 서비스 화면. 계정·배포 시점에 따라 화면과 메뉴 이름이 달라질 수 있습니다.

RAG를 업무에서 경험하기

관련 자료를 검색해 생성의 근거로 쓰는 흐름입니다. 이 실습은 NotebookLM의 검색·인용을 활용하며, 외부 AI에 내용을 복사하면 그 AI는 전달받은 자료를 사용합니다. 외부 AI가 내 노트북을 자동 검색하도록 연결되는 것은 아닙니다.

등록 전 확인할 사항과 자료 활용 방법

공개 자료도 최신본인지 확인하세요. 학교 홈페이지 공개본의 개정 여부는 학교 담당자에게 확인할 수 있습니다. 법령·조례의 시행일과 지침의 적용 학년도를 질문에 적고, 서로 다른 기준은 합쳐 단정하지 않습니다.

학교 규정집의 표지는 2026학년도로 되어 있지만 일부 머리말에는 2025학년도 표기가 남아 있습니다. 같은 게시글의 개정 사항과 함께 대조하고 학교 적용 최신본을 확인하세요.

배포용 자료에는 학생·교직원의 개인 명단, 상담 기록, 실제 성적 자료를 포함하지 않습니다. PDF·TXT 변환본은 검색 편의를 위한 사본이며 원문이 최종 확인 기준입니다. HWP·HWPX를 PDF로 바꿨다면 표와 각주를 대조하세요.

자료 묶음의 목록 파일에서 원문 URL·다운로드일·형식·해시를 확인할 수 있습니다. 변경된 자료는 원문에서 다시 받고 노트북의 기존 소스를 교체하세요.

A / WORD · HWPX

공문을 업무 문서로

필수 항목을 찾고 준비 사항·담당자·기한을 문서 양식에 반영합니다.

  1. NotebookLM에서 근거를 확인합니다.
  2. 작업 요청과 확인한 자료를 외부 AI에 전달합니다.
  3. 초안을 문서 편집 기능 또는 한글에서 다듬습니다.
  4. 확정 정보와 확인 필요 사항을 구분합니다.
B / POWERPOINT

보고서를 설명 자료로

같은 내용을 교직원 설명용 5장으로 재구성합니다. 파일 생성이 막히면 슬라이드별 표를 사용합니다.

  1. 대상과 발표 시간부터 정합니다.
  2. 슬라이드별 메시지 하나를 고릅니다.
  3. 발표자 메모와 근거를 함께 붙입니다.
  4. PPT를 열어 글자·표·넘침을 확인합니다.
C / EXCEL

업무와 예산을 표로

가상 예산 CSV를 계산 가능한 표로 바꿉니다. 합계와 수식을 직접 대조합니다.

  1. CSV를 업로드하거나 내용을 붙여 넣습니다.
  2. 수량 × 단가 수식과 합계를 만듭니다.
  3. 예산 상한과 차액을 확인합니다.
  4. 빈 셀·문자 숫자·중복 행을 점검합니다.

HWPX 자동화 확장 시연은 이렇게 진행합니다

공개 PDF에서 정보를 추출하고 항목별 데이터로 정리한 뒤, 미리 검증한 HWPX 양식의 제목·목적·일정·내용 칸에 넣습니다. 문서명과 저장 폴더 규칙을 지정하고 한글에서 열어 표·쪽 나눔을 확인합니다.

별도 실행 환경: kordoc·hwpx-skill 등은 강사가 사전 설치·검증해 시연하는 도구입니다. 이 사이트는 HWPX 변환 서버나 NEIS 자동 입력 기능을 제공하지 않습니다. 일반 XML로 저장하는 것만으로 정상적인 HWPX가 되지는 않습니다.

무료 계정과 문서 형식에 관한 안내

무료 기능에도 메시지·파일·생성량 제한이 있습니다. 각자의 계정과 학교 관리 설정에 따라 접근 가능 여부가 다릅니다. 유료 체험 가입이나 API 결제는 실습의 필수 조건이 아닙니다.

NotebookLM의 공식 소스 목록에는 PDF·DOCX·TXT·복사 텍스트 등이 있으며 HWP·HWPX는 직접 지원 목록에 없습니다. 검색용 사본과 편집할 원본을 따로 관리합니다. PDF에서 HWPX로 변환할 때는 텍스트·표·서식 복원 품질을 확인합니다.

사이트의 자료와 화면은 연수용이며, 학교의 공식 업무 시스템이나 기관 승인 AI 서비스가 아닙니다. 실제 학생 정보·내부 업무 자료의 사용은 소속 기관의 허용 범위를 따릅니다.
