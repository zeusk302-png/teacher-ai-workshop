문서 작성 및 검토

아래는 특정 서비스의 실제 화면 설명이 아닌 공통 작업 절차입니다. 파일 생성 가능 여부와 메뉴는 사용하는 계정·서비스에서 직접 확인하세요.

  1. 검색한 데이터로 초안 작성

    홈의 문서 실습에서 작업 요청을 만들고 선택한 외부 AI에 붙여 넣습니다. 인용을 확인한 공개 발췌문·자료명·쪽·적용 시점을 함께 전달하세요. 초안에서 원문에 없는 이름·날짜·수치와 ‘확인 필요’를 먼저 검사합니다.

  2. 파일 요청 또는 텍스트로 이어가기

    계정에서 파일 생성이 가능하면 DOCX·PPTX·XLSX 중 선택한 형식으로 요청하고 다운로드합니다. 파일이 생성되지 않거나 사용량이 막히면 본문·슬라이드별 표·표 데이터를 복사해 편집기에 붙여 넣습니다. 확장자만 바꾸어 저장하지 않습니다.

    검토한 초안을 선택한 문서 형식으로 제공하세요. 파일 생성이 가능하면 DOCX/PPTX/XLSX 파일과 사람이 확인할 항목을 주세요. 불가능하면 Word용 제목·본문·표, PowerPoint용 슬라이드 번호/제목/핵심 내용/발표자 메모/출처 표, Excel용 열 이름·데이터·수식 설명을 복사 가능한 텍스트로 주세요. 기존 날짜·숫자·인용은 유지하고 모르는 항목은 [확인 필요]로 표시하세요.

  3. Word·PowerPoint·Excel에서 열어 검사

    Word / 한글

    파일을 열거나 본문을 붙여 넣습니다. 제목·필수 항목·인용·표·쪽 나눔을 확인하고 원문과 이름·날짜·수치를 대조하세요. 한글은 실제 지원 형식과 양식을 확인합니다.

    PowerPoint

    파일을 열거나 슬라이드별 내용을 옮깁니다. 한 장에 메시지 하나, 글자·표 넘침·발표자 메모·출처를 확인하고 슬라이드 쇼에서도 읽어보세요.

    Excel

    XLSX 또는 가상 예산 CSV를 엽니다. 수량×단가와 합계 수식을 확인하고 2개 행을 직접 계산해 대조합니다. 숫자 형식·빈 셀·중복 행·수식 오류도 검사하세요.

  4. 검토본으로 저장

    수정한 파일을 다시 열어 결과를 확인합니다. 출처·적용 시점과 확인 필요 사항을 남기고, 실제 업무 사용 전 담당자가 검토합니다.
