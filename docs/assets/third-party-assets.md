# 로컬 시각 자산

- Bootstrap Icons v1.11.3: https://github.com/twbs/icons/tree/v1.11.3/icons — 원본 SVG(시계 아이콘 포함), MIT. LICENSE는 icons/LICENSE.
- Pretendard Variable v1.3.9: https://github.com/orioncactus/pretendard/tree/v1.3.9 — 로컬 WOFF2, SIL OFL 1.1. LICENSE는 fonts/LICENSE.
- 학교 로고: school-logo-source.json. 원본 PNG는 변경하지 않음.
- 책상 이미지: course-desk-source.json. 사용자가 제공한 장식 이미지이며 실제 서비스 증거로 표시하지 않음.
- 문서 3장 그림: school-document-flow.provenance.json. 사용자가 선택한 화면의 그림을 참고해 Image Gen으로 제작한 장식 자산.
- course-qr.png: 공개 강의 사이트 주소로 만든 QR 코드. 완성된 PDF의 표지와 마지막 쪽에서 주소 해독을 확인함.
